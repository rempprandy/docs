BlackQuant provides two dedicated support tiers tailored for distinct inquiries:

## Knowledge Base

**Apps → Knowledge Base.** A searchable library of detailed technical articles covering every platform tool, protocol mechanism, and security procedure.

Use the Knowledge Base for questions with documented specifications: how protocol yield compiles, how Smart Executors operate, or why a confirmation threshold applies.

## The AI assistant

An intelligent assistant widget accessible across the application. The assistant is grounded directly in our verified documentation library, ensuring answers remain factual and accurate.

<Info>
The assistant answers strictly from indexed platform documentation. If an edge case is unindexed, the assistant will inform you directly so you can escalate to our human support team.
</Info>

Sample queries ideal for the assistant:
* "What confirmation count does USDT require on TRC-20?"
* "What is the compounding epoch frequency of the Yield Farmer?"
* "Which Smart Executors are unlocked on the Growth tier?"

Inquiries best directed to a support specialist:
* "My deposit status displays PARTIALLY_PAID: here is the blockchain transaction hash."
* "My identity verification requires manual document clarification."
* "An on-chain settlement shows a discrepancy with my dashboard summary."

## Help Desk

**Others → Help Desk.** Connects directly with our technical support team.

When opening an inquiry, please include:

| Information | Purpose |
| --- | --- |
| Blockchain Transaction Hash | Allows staff to verify on-chain confirmations directly |
| Asset and Network | Helps identify potential cross-network misrouting |
| Ledger Entry ID or State | Locates your transaction immediately |
| Screenshot of Issue | Illustrates UI discrepancies directly |
| Expected vs Observed Behavior | Distinguishes between configuration preferences and bugs |

<Info>
Providing an on-chain transaction hash allows support to resolve deposit inquiries via a direct block explorer lookup.
</Info>

The **Priority Support** permanent [add-on](/billing/add-ons) ($150) provides guaranteed 4-hour response times, 24/7. Elite subscriptions include a dedicated account manager.
