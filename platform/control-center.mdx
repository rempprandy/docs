The primary landing interface upon signing in: **Main → Control Center**, or `/dashboard`.

## What is on the screen

| Section | Description |
| --- | --- |
| Balance Overview | Current USD ledger balance, derived from historical transactions |
| Capital Activity Chart | Net fund movements per day over the selected timeframe |
| Account Security & Verification | Real-time KYC verification and 2FA status indicators |
| System Notifications | Recent alerts from the notification bell menu |

## The activity chart

Displays one bar per **calendar day** in UTC. Deposits and earnings are positive credits, subscriptions and executor stakes are debits, and each bar indicates net activity for that day.

| Window | Duration |
| --- | --- |
| 7 days | 7 days (default) |
| 30 days | 30 days |
| 90 days | 90 days |

<Info>
Tabs are labeled in precise days rather than vague ranges. The chart renders a consistent chronological timeline where days with no activity display a zero bar, providing an accurate view of elapsed time.
</Info>

## Account status alerts

Two essential security prerequisites are monitored directly in the Control Center:

* **Identity Verification**: Required prior to processing capital withdrawals. Links to [Verify your identity](/getting-started/verify-your-identity).
* **Two-Factor Authentication (2FA)**: Strengthens sign-in security. Links to [Secure your account](/getting-started/secure-your-account).

Sidebar badges reflect status updates in real time, showing outstanding security items at a glance.

## Notification preferences

System alerts are organized into distinct categories accessible via the top-bar bell menu:

| Kind | Purpose |
| --- | --- |
| `WELCOME` | Account onboarding and credential confirmation |
| `SECURITY` | 2FA modifications, credential resets, and new login events |
| `SYSTEM` | Deposit confirmations, executor harvests, plan renewals, and platform updates |

You can customize notification preferences under **Personal → My Profile**:

| Channel | Default | Description |
| --- | --- | --- |
| Signals | Enabled | Real-time quantitative signal alerts |
| Positions & Executors | Enabled | Trade fills, harvest epoch completions, and rebalances |
| Withdrawals | Enabled | Payout request status and on-chain dispatch confirmations |
| Referrals | Disabled | Optional notifications for downstream team purchases |

## Dashboard navigation

The application sidebar organizes platform tools into four primary sections:

```
Main       Control Center
Apps       Treasury · Fund Account · Signal Plan · Positions
           Withdrawals · Referral Hub · Signal Engine · Knowledge Base
Personal   My Profile · 2FA / Auth Guard · Reset Credentials · Verification
Others     Help Desk · Sign Out
```

The **Signal Engine** link displays an active indicator when live feeds are connected. If an external engine is offline, the interface explicitly reports the disconnection rather than displaying placeholder figures. See [Signal Engine](/platform/signal-engine).
