## Deposit issues and states

| State | Root Cause | Recommended Action |
| --- | --- | --- |
| `WAITING` prolonged | External wallet has not broadcasted transaction | Check your sending wallet transaction history and mempool status |
| `CONFIRMING` | Normal: block confirmations accumulating | Allow native blockchain validators to finalize blocks (1 on XRP to 32 on SOL) |
| `PARTIALLY_PAID` | Transfer amount falls below required invoice | Contact [Help Desk](/platform/knowledge-and-help) with the transaction hash |
| `FAILED` | Transaction dropped from mempool or reverted | Check your external wallet: assets typically remained unspent |
| `EXPIRED` | Payment window elapsed prior to transfer | Generate a **new** deposit address; do not broadcast to expired addresses |
| `CONFIRMED` but balance unchanged | Gateway webhook latency | Allow a few minutes for callback synchronization, then open a support ticket |

### Deposit not detected on-chain

1. Confirm that you broadcasted on the **exact native network shown on the deposit page**.
2. Confirm the transaction amount exceeded the stated **minimum threshold**.
3. Confirm that required **memos or destination tags** were correctly attached.
4. Locate the transaction hash on a public block explorer to confirm network broadcast.

<Danger>
Funds broadcast over incorrect or unsupported blockchain networks cannot be recovered by BlackQuant, payment gateways, or network validators.
</Danger>

## Authentication & sign-in issues

### "Something went wrong on our end"

This represents a generic authentication failure. The most common causes:
1. **Incorrect password**: Verify capitalization and character entry.
2. **Account created via GitHub OAuth**: Accounts created with GitHub do not have a password set. Authenticate using the GitHub button, or set a password via **Reset Credentials**.
3. **Invalid or expired 2FA token**: Ensure device clock sync is enabled.
4. **Stale browser session**: Clear cookies for the domain and retry.

Authentication errors are intentionally uniform to prevent brute-force email enumeration.

### 2FA codes repeatedly rejected

Almost always caused by local device clock drift. Verification allows **one step of clock skew** (±30 seconds). Enable automatic network time synchronization on your mobile device.

If the clock is synchronized and codes still fail, authenticate using an unused single-use recovery code, then re-enroll your authenticator app under **2FA / Auth Guard**.

### Session expired unexpectedly

If "Remember me" is left unchecked, sessions expire after **24 hours**. When checked, sessions persist for 30 days.

## Subscription & add-on purchase issues

| Message | Meaning | Resolution |
| --- | --- | --- |
| *"That subscription is already active."* | Plan tier is already active | Wait for current term to expire, or upgrade to a higher tier |
| *"You already own that."* | Permanent add-on already owned | Add-ons are permanent and do not require repurchasing |
| *"That item isn't available."* | Deprecated item identifier | Refresh catalog view |
| Insufficient balance | Balance below required cost | Deposit funds or complete direct crypto checkout |

## Smart Executors & Positions

| Issue | Explanation | Action |
| --- | --- | --- |
| Executor shows Stopped / Paused | Staking cycle was paused manually | Click the **Restart** button in the executor header to resume |
| Principal not in available balance | Staking capital is held during active run | Principal and accumulated net yield return to available balance when the executor completes or is stopped |
| Compounding mode adjustment | Reinvest vs Cash payout | Toggle the Compounding Mode switch on the Yield Farmer dashboard at any time |

## Identity verification issues

| Rejection Reason | Recommended Solution |
| --- | --- |
| Document corners cropped | Place document on a flat surface with ample margin on all sides |
| Reflection / Glare | Move away from direct overhead lighting on laminated IDs |
| Blurry or illegible text | Ensure camera focus is sharp before capturing |
| Expired document | Provide a valid, unexpired government-issued ID |
| Incomplete sides | Submit both front and reverse sides for licenses and ID cards |
| File size limit exceeded | Keep image under 8 MB (JPEG, PNG, or WebP) |

Rejections are not permanent: review the note provided and re-submit.

## Signal Engine connectivity

### "Not connected" indicator

Indicates the external Signal Engine feed is offline or undergoing scheduled maintenance.

This notice is intentional: the interface refuses to simulate artificial signals when live feeds are unavailable. Feeds reconnect automatically once upstream processes resume.

### Feed timeout errors

Signal requests enforce a **5-second timeout**. If the feed pauses, refresh the browser window or check `/api/health`.

## Referral tracking inquiries

| Symptom | Cause |
| --- | --- |
| Referral not attributed | Attributions use a 30-day cookie window: registration may have occurred after cookie expiration or across different browsers |
| Downstream member visible but $0 commission | Commissions are awarded exclusively on **purchases**, never on deposits |
| Commission lower than expected | Tier 1 awards 5% and Tier 2 awards 2% of qualifying purchase prices |

## Escalating to support

When opening a support request, include your blockchain transaction hash, cryptocurrency asset and network, deposit state, and screenshots where applicable. See [Knowledge Base & Help Desk](/platform/knowledge-and-help).
